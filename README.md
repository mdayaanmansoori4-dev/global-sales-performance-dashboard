# 📊 Global Sales Performance Dashboard

An interactive Power BI dashboard analyzing global sales performance from FY2011–2016 across 5 countries and 3 product categories (Bikes, Accessories, Clothing).

)

## What's Inside

- **112,000+ rows** of cleaned transactional sales data
- **Star schema** data model with a proper date dimension table
- **15+ DAX measures** — Total Revenue, Profit Margin %, YoY Growth, MTD, Top-N Ranking, and more
- **5 interactive slicers** — Date, Country, Product Category, Age Group, Gender
- **7 visuals** — KPI cards, trend line, bar charts, donut chart, table, and a revenue/margin combo chart
- **Custom theme** — consistent color palette and layout across every visual

## Tools Used

Power BI Desktop · DAX · Power Query · Python (data cleaning)
